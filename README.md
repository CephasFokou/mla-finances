# MLA Finance Management System

Système de gestion financière pour la chorale MLA (ICC Yaoundé) : suivi des contributions, projets/enveloppes, retraits, rapports et médias, avec une page publique de don.

Monorepo :
- `backend/` — API Spring Boot 3 / Java 21 / PostgreSQL / Liquibase (voir `backend/README.md`).
- `frontend/` — application React / TypeScript (à venir).

Références validées : Cahier des Charges v1.1 et Document Technique v1.2 (conservés dans le Projet claude.ai "MLA - FINANCES").
